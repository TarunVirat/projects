# XGBoost Classification Implementation

This project demonstrates a complete classification pipeline using **XGBoost**, a powerful and efficient gradient boosting algorithm widely used for tabular data. The notebook walks through loading data, preprocessing, training an XGBoost model, evaluating its performance, and visualizing feature importances.

## 📁 File

- `XgboostBoost Classification Implementation.ipynb` – Main notebook implementing the classification workflow.

## 🔍 Features

- Data preprocessing
- Model training using XGBoost
- Model evaluation with:
  - Accuracy
  - Precision, Recall, F1-Score
  - Confusion Matrix
  - ROC Curve
- Feature importance visualization

## 📦 Requirements

Install the following Python libraries before running:

```bash
pip install xgboost scikit-learn pandas matplotlib seaborn
```

## 🚀 How to Run

1. Clone or download this repository.
2. Install the dependencies listed above.
3. Launch Jupyter Notebook or Jupyter Lab.
4. Open the notebook file and run the cells sequentially.

## 🧠 Algorithm Used

- **XGBoost**: An optimized gradient boosting library designed to be highly efficient, flexible, and portable. It is known for its speed and performance on structured data.

## 📈 Evaluation Metrics

- Accuracy
- Precision
- Recall
- F1 Score
- ROC-AUC
